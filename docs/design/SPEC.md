# KeyClaim 界面规格

## 产品主线

KeyClaim 是一个常驻后台的单任务工具，不是设备管理后台。用户打开窗口时只需要确认键盘当前在哪台电脑、另一台电脑是否在线，以及自动跟随是否开启。

## 首屏信息架构

界面固定为一个紧凑单页，不设置侧栏和页面导航：

1. 顶部：产品名称与版本号、服务状态、设置入口。
2. 主状态：当前键盘归属与自动跟随说明。
3. 设备：Mac 与 Windows 的在线状态、通道和手动切换兜底。
4. 常用设置：自动跟随、登录时启动。
5. 底部：输入监听、局域网、本地隐私和最近一次动作。

通道、配对码和输入灵敏度收进一个直接打开的设置对话框，不再出现“设置页里再打开设置”的重复层级。

## 可读性

- 默认正文为 15px。
- 状态说明和辅助文字不低于 14px。
- 小型标签不低于 13px；产品版本号可使用 12px，但必须紧邻产品名称。
- 设备名称为 17px，当前归属为 26px。
- 文字弱化优先使用颜色和字重，不使用 8–10px 小字号。

## 设计 Token

- 背景：冷灰 `#F4F5F7`。
- 面板：白色 `#FFFFFF`。
- 主文字：`#17191D`；次级文字：`#626B78`。
- 强调色：克制蓝 `#1769E0`；成功色：`#18985A`。
- 边框：`#DFE3E9`，1px。
- 圆角：控件 9–11px、主要面板 13–14px。
- 阴影：仅突出当前归属主卡，不给所有区域叠加阴影。
- 动效：120–170ms，并遵守 `prefers-reduced-motion`。

## 窗口与状态

- 默认窗口为 900 × 610，最小窗口为 700 × 560。
- 支持在线、离线、正在连接、当前归属、切换中和错误状态。
- 所有按钮覆盖 hover、active、focus、disabled 和 loading。
- 深色模式保持相同的信息层级和字号。
- 关闭窗口后继续驻留菜单栏，登录启动时不主动弹出主窗口。

## 品牌图标

- 延续 Fei Notes 与非-剪贴板的黑帽、眼镜、口罩角色识别。
- 构图使用键盘、两台通用电脑和一条连接路径表达“键盘归属切换”。
- 不使用 Apple、Windows 或 Logitech 商标，不嵌入文字和数字。
- 1024px 原图保存在 `docs/assets/keyclaim-icon.png`，平台图标由 Tauri CLI 统一生成。
