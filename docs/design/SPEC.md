# KeyClaim · 键来界面规格

## 产品主线

KeyClaim（中文名“键来”）是常驻菜单栏的静默切换工具，不是设备管理后台。正常情况下，用户只需要感知键盘当前所在通道，并控制自动跟随与开机自启。

## 紧凑主面板

主面板采用约 `404 × 202` 的菜单栏下拉浮层：

1. 顶部仅展示 `KeyClaim`、中文名“键来”和设置入口。
2. 中间根据实际主机数据动态生成通道；配置两个通道就显示两个，配置三个才显示三个，不补空位。
3. 每个通道同时展示通道编号与设备友好名称，当前通道使用浅蓝底、蓝色文字和选中标识。
4. 底部将“自动跟随”和“开机自启”横向并列。
5. 正常状态不展示在线列表、手动切换、硬件型号、诊断信息、最近动作或刷新按钮。
6. 权限或运行异常时，只增加一条短提示和必要处理入口。

## 多通道原则

- 渲染数量来自实际主机集合，不以键盘理论最大通道数占位。
- 当前双端后端缺省使用 `localHost + peerHost`；前端预留 `hosts` 集合以支持未来三主机。
- 通道按编号排序并去重。
- 通道是状态指示器，不设计成手动切换按钮；硬件 Easy-Switch 仍是手动兜底。

## 视觉 Token

- 浮层：冷白 `#FBFBFC`；深色模式为 `#1E2024`。
- 窗口边界与界面表面合一：不在透明窗口画布内再嵌套一张带外边距和投影的卡片。
- 主文字：`#1C2027`；次级文字：`#6D7480`。
- 强调色：克制蓝 `#1769E0`；选中底色：`#EDF4FF`。
- 分隔：半透明深灰，优先使用留白和细分隔线，不堆叠卡片。
- 圆角：主浮层 `14px`，通道选择区 `11px`，控件 `8–9px`。
- 字号：品牌 `17px`，设备名 `15px`，常用设置 `14px`，通道标签 `13px`。
- 动效：`120–170ms`，并遵守 `prefers-reduced-motion`。

## 交互与状态

- 设置按钮支持点击与 `⌘,` / `Ctrl+,`。
- macOS 默认不显示主窗口、不占 Dock；单击菜单栏图标后，浮层以图标中心为锚点向下展开。
- 再次单击菜单栏图标或点击浮层外部，主面板立即收起，后台自动跟随继续运行。
- 面板在多显示器和屏幕边缘自动约束位置，不超出当前菜单栏所在屏幕的可用区域。
- 设置界面允许本机使用通道 `1 / 2 / 3`。
- 所有按钮和开关覆盖 hover、active、focus、disabled 与 loading 状态。
- 设置打开或出现必要异常提示时，窗口按内容临时增高；关闭后恢复紧凑尺寸。
- 设置页提供低强调度的“退出键来”，用于真正结束菜单栏后台进程。
- 登录启动时只驻留菜单栏，不主动弹出主面板。
- 保留浅色、深色和减少动态效果适配。

## 品牌边界

- 英文品牌 `KeyClaim` 保留，中文名“键来”作为补充名称，不替换仓库名、包名或 Bundle Identifier。
- 界面、窗口标题、菜单栏提示、项目描述和文档使用 `KeyClaim · 键来`。
- 延续现有黑帽、眼镜、口罩角色图标；平台图标仍由 Tauri CLI 统一生成。
