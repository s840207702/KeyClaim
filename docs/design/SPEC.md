# KeyClaim 界面规格

概念图：`keyclaim-overview-concept.png`

## 产品主线

KeyClaim 是一个本地优先的双电脑键盘归属工具。Windows 使用 MX Keys 通道 2，MacBook Pro 使用通道 3；任一电脑检测到本地物理鼠标或触控板操作后，向当前持有键盘的电脑发起召回。

## 首屏信息架构

- 左侧固定导航：总览、设备、规则、诊断、设置。
- 顶部标题：键盘会跟随你的工作位置。
- 右上角：自动召回总开关。
- 中央拓扑：Windows 工作站、MX Keys、MacBook Pro 三者的连接和当前归属。
- 状态轨道：最近输入、当前归属、局域网状态、休眠恢复状态。
- 下方双栏：生效规则、最近活动。
- 底部：可展开的诊断区域。

## 设计 Token

- 主背景：纯白 `#FFFFFF`。
- 侧栏：冷灰 `#F7F8FA`。
- 主文字：`#15171A`；次级文字：`#6B7280`。
- 强调色：克制蓝 `#1769E0`；成功色：`#22A559`。
- 边框：`#DEE3EA`，1px。
- 圆角：控件 8px、主要面板 12px。
- 阴影：只用于当前键盘归属面板，短而柔和。
- 字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。
- 动效：160–220ms；遵守 `prefers-reduced-motion`。

## 响应式和状态

- 最小窗口宽度 1080px；较窄时压缩拓扑间距，不隐藏关键状态。
- 支持在线、离线、睡眠、正在连接、当前归属和错误状态。
- 所有按钮覆盖 hover、active、focus、disabled、loading。
- 深色模式沿用同一层级，不使用玻璃拟态或高饱和渐变。

## 图标规格

- 统一使用 18–20px、1.7px 圆角线性图标。
- 导航图标：总览、设备、规则、诊断、设置。
- 状态图标：鼠标、触控板、键盘、网络、恢复、在线圆点。
- 图标颜色继承文字；选中状态使用强调蓝。
