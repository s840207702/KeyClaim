# KeyClaim 开源准备检查

检查日期：2026-10-10。应用版本：0.2.6。检查基线：`3d6f69ef8e603b84621f02379dba03e92b681f7f`，包含此前全部 33 个提交与远端标签。本次后续提交仅补齐开源文档、许可元数据、忽略规则与两个开发间接依赖，不修改应用功能、设备配置、配对码或防火墙，也不替换已经发布的两个安装包。

## 结论

已补齐公开开源仓库的基本材料，可以按 MIT 发布源码。但“可以开源”不代表“所有设备都兼容”或“已完成正式签名和长期稳定性验收”。安装包、兼容性与安全限制必须继续向使用者说明。

## 已发布安装包的验证范围

0.2.6 的 Windows x64 NSIS 和 Apple Silicon DMG 均已在现有两台机器实际安装、启动，版本为 0.2.6，各自单进程，UDP/TCP 45823 归属于对应进程，原配置保留。上传哈希与本地安装包一致。

Windows 有真实键盘召回成功记录，同时也有超时和未找到设备记录。新打包的 Mac 应用只完成启动、输入监听和握手检查；完整双机持续切换仍未验收通过。该结论不因仓库公开而改变。

安装包生成于本次文档补齐前，其源码提交仍为基线提交，不移动已有 v0.2.6 标签。为现有发布包补充许可附件，保留原安装包 SHA256；下载、再分发安装包或旧标签源码时应同时携带许可附件。

## 仍未完成的工作

1. Windows Authenticode 签名与 macOS Developer ID 签名、公证：当前包可能被系统提示或拦截，不能承诺在其他电脑无提示安装。
2. 跨设备与系统兼容性测试：目前主要覆盖现有 MX Keys 接收器组合，没有 Intel Mac、Linux、纯蓝牙及所有型号的支持承诺。
3. 完整双机稳定性验收：包括连续快速切换、接收器重连、休眠恢复与长期运行；现有超时问题尚不能标为已彻底解决。
4. 安全加固：随机默认配对码与首次配置引导、加密通信、本机安全存储、CSP 与异常连接资源限制仍未完成。目前必须手动设置自己的随机配对码，并只在可信局域网使用。
5. 包内许可证展示：本次提供外置许可附件，后续安装器仍应内置版权与第三方许可材料。

行为准则、英文版说明、更多演示、Intel Mac 包与自动 CI 可以按后续实际需要增加，不属于开源许可证生效的必要条件。本项目目前不承诺固定响应时限、专门支持服务或漏洞奖励计划。
